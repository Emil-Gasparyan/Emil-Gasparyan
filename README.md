## Projects

### [Morning Desk](https://github.com/emilgasparyan-droid/morning-desk)

A news briefing you listen to instead of scroll. Each user chooses their topics, the outlets they trust and when they listen. The app collects the latest headlines, turns them into a short podcast-style script and records it as audio.

[Live app](https://morning-desk-opal.vercel.app)

- Passwordless email sign-in, with each user's data isolated by row-level security in Postgres
- Topic and source preferences that shape every episode, including custom search topics
- Audio episodes recorded with ElevenLabs and kept for seven days
- Continuous deployment to Vercel from GitHub

**Stack:** Next.js, TypeScript, Tailwind CSS, Supabase, ElevenLabs, Vercel
